### 已知问题(M0 遗留,不阻塞验收)

1. **SSAO 未实现**——按计划放高档位,M8 接入(quality-presets 已留 `ssao` 字段)。
2. **微信小游戏/APP PAL 实现未做**——按计划属 M9 POC;接口已冻结,检测到非 web 平台会抛出明确指引。
3. **触屏虚拟摇杆未实现**——按计划属 M1;PAL 触摸事件通道已就绪。
4. **画质切换暂无 UI 入口**——`QualityManager` 已可用(F3 显示当前档),设置面板属 M8。
5. **冷启动 4~6 秒**(Vite 首次模块转换 + 地形/植被程序化生成);生产构建无此问题,且加载页全程有进度反馈。
6. **字体源 CDN 依赖网络**——`npm run fonts` 在 GitHub 直连失败时自动走加速镜像并缓存;彻底离线时可手动 `--in` 指定字体文件,运行时亦有三级降级兜底。
